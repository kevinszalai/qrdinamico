Falta conectar Firebase

Este archivo todavía tiene la configuración de ejemplo. Para verlo funcionando:

  1. Creá un proyecto en console.firebase.google.com
  2. Activá Authentication → Email/Password
  3. Activá Firestore Database
  4. Copiá el objeto firebaseConfig del proyecto y pegalo al inicio de este archivo, reemplazando los valores de ejemplo
